# Spine

One five-tab chrome. Three corpora as files.

Open on a phone:
1. [app.html](./app.html) — the running shell (GitHub → file → raw, or any static host)
2. [corpora/](./corpora) — Continuity / Nightglass / Provenance JSON
3. [docs/](./docs) — how each corpus uses the chrome

```bash
npm i && npm run dev   # optional Vite path once src/App.tsx exists
```

New product = new JSON in `corpora/`, not a new tab bar.
